# Como rodar o projeto 

## backend - comandos

- Dê cd backend
- npm i
- npm run dev


## front end - comandos 

-  cd mobile
- npm i
- npx expo start
- teclar w (inicia a instância web do expo)


## Acesso ao banco de dados

- Nome do db: presenca_plus
- Coleções: users , events, attendances
- Porta de saída do banco de dados: Padrão 27017
