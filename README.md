# Como rodar o projeto 

## backend 

- Dê cd backend
- npm i
- npm run dev


## front end 

- Dê cd mobile
- npm i
- npx expo start

## Acesso ao banco de dados

- Por padrão, o mongoDB Atlas aceita apenas alguns endereços IP cadastrados no Cluster, envie seu endereço IP consultando em https://meuip.com.br/
